Finite samples only, 1–4,194,304 values. summary(values,sample,result[4]) returns mean, standard deviation (sample=0 population, 1 sample), min, max. percentile(values,p) uses linear interpolation on sorted values, p=0–100. countRange is inclusive, -1 on failure. histogram(values,low,high,bins) counts equal-width bins, left inclusive/right exclusive except last inclusive; ignores values outside the range, 1–65536 bins. compare(first,second,result[2]) returns MAE and MSE for equal-length aligned arrays. Invalid calls leave output arrays unchanged; percentile returns NaN. GIM-16.01–09/.11–12 numerical foundations, GIM-16.10 preserves existing RasterImage.pixelAt. ## Raster regions

RasterImage.analysisSamples(x,y,width,height,channel,controlled,float[] output) extracts row-major regional samples (0–255); channel 0–3 RGBA, 4 Rec.709 weighted encoded RGB luma (not linear-light luminance). controlled=0 raw buffer, 1 existing export controls with byte rounding. No alpha weighting or implicit exclusion of transparent pixels. Output must contain exactly width*height values, maximum 4,194,304. Invalid requests preserve output and image. Use MediaAnalysis.summary/percentile/countRange/histogram/compare for statistics; proportion is count divided by region sample count. ## MediaColor

Import MediaAnalysis to access MediaColor.convertColor(sourceSpace,destinationSpace,inputColor[3],outputColor[3]). IDs: 0 encoded sRGB, 1 linear sRGB, 2 HSV, 3 HSL, 4 CIELAB D65, 5 CIELCH(ab) D65, 6 grayscale output (linear Rec.709 luminance encoded in sRGB, repeated RGB). RGB/S/V/L(HSL) use 0–1; hue degrees wraps; Lab/LCH lightness 0–100, a/b signed, chroma nonnegative. Lab/LCH direct conversion preserves chromatic coordinates; conversion to RGB clips linear gamut. No ICC/HDR; alpha is independent, no image storage format change. Invalid inputs preserve output.
