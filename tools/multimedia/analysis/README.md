# MediaAnalysis

Import `@import "MediaAnalysis";`. Shared numeric arrays for raster, audio, video and other domains. Finite samples only, 1–4,194,304 values. summary(values,sample,result[4]) returns mean, standard deviation (sample=0 population, 1 sample), min, max. percentile(values,p) uses linear interpolation on sorted values, p=0–100. countRange is inclusive, -1 on failure. histogram(values,low,high,bins) counts equal-width bins, left inclusive/right exclusive except last inclusive; ignores values outside the range, 1–65536 bins. compare(first,second,result[2]) returns MAE and MSE for equal-length aligned arrays. Invalid calls leave output arrays unchanged; percentile returns NaN. GIM-16.01–09/.11–12 numerical foundations, GIM-16.10 preserves existing RasterImage.pixelAt. Regional/channel extraction and raster integration remain pending. No new dependencies. Group analysis-numeric: 30 checks, not yet executed.

## Raster regions

RasterImage.analysisSamples(x,y,width,height,channel,controlled,float[] output) extracts row-major regional samples (0–255); channel 0–3 RGBA, 4 Rec.709 weighted encoded RGB luma (not linear-light luminance). controlled=0 raw buffer, 1 existing export controls with byte rounding. No alpha weighting or implicit exclusion of transparent pixels. Output must contain exactly width*height values, maximum 4,194,304. Invalid requests preserve output and image. Use MediaAnalysis.summary/percentile/countRange/histogram/compare for statistics; proportion is count divided by region sample count. GIM-16 regional/channel analysis, mean sampling and aligned image comparison foundations; arbitrary selection masks and perceptual comparison remain outside this adapter. ## MediaColor

Import MediaAnalysis to access MediaColor.convertColor(sourceSpace,destinationSpace,inputColor[3],outputColor[3]). IDs: 0 encoded sRGB, 1 linear sRGB, 2 HSV, 3 HSL, 4 CIELAB D65, 5 CIELCH(ab) D65, 6 grayscale output (linear Rec.709 luminance encoded in sRGB, repeated RGB). RGB/S/V/L(HSL) use 0–1; hue degrees wraps; Lab/LCH lightness 0–100, a/b signed, chroma nonnegative. Lab/LCH direct conversion preserves chromatic coordinates; conversion to RGB clips linear gamut. No ICC/HDR; alpha is independent, no image storage format change. Invalid inputs preserve output. ## MediaPalette

Indexed representation uses caller-owned int[] indices and flat RGBA8 palette, 1–256 entries. encodeIndexed(width,height,rgba,palette,mode,indices) maps pixels to nearest palette color by squared RGBA distance (ties use earliest entry); mode 0 nearest, 1 Floyd-Steinberg RGB diffusion, left-to-right, no alpha diffusion. decodeIndexed expands indices into RGBA; reorderPalette(indices,palette,newOrder) remaps indices and palette together, newOrder maps new index to old. Invalid inputs preserve outputs; reorder rejects aliasing. Limits 4096 per axis, 4,194,304 pixels. Explicit user palette, no automatic palette extraction, indexed file encoding or higher-precision storage. GIM-14.03/.15–17 partial foundations. Group color-indexed: 33 checks, not executed.

## MediaCurve

Shared numeric value remapping, independent of time and media type, imported through MediaAnalysis. evaluate(inputKnots,outputKnots,inputValue,interpolationMode) returns a scalar or NaN on invalid input. apply(inputKnots,outputKnots,inputValues,interpolationMode,outputValues) transforms arrays; buildLUT(inputKnots,outputKnots,rangeLow,rangeHigh,interpolationMode,outputValues) samples inclusive endpoints uniformly. Modes 0 step (left hold), 1 linear, 2 smoothstep per interval. Strictly increasing finite input knots, 2–65536, finite outputs; arbitrary numeric range, endpoint clamping outside curve; no output clipping or unit conversion. Array limit 4,194,304 samples. Invalid calls preserve output, explicit in-place apply permitted. GIM-15 shared numerical remapping foundation, not full individual color adjustments; raster/audio/MIDI adapters and domain-specific tests remain separate.
