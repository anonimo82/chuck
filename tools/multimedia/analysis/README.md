# MediaAnalysis

Import `@import "MediaAnalysis";`. Shared numeric arrays for raster, audio, video and other domains. Finite samples only, 1–4,194,304 values. summary(values,sample,result[4]) returns mean, standard deviation (sample=0 population, 1 sample), min, max. percentile(values,p) uses linear interpolation on sorted values, p=0–100. countRange is inclusive, -1 on failure. histogram(values,low,high,bins) counts equal-width bins, left inclusive/right exclusive except last inclusive; ignores values outside the range, 1–65536 bins. compare(first,second,result[2]) returns MAE and MSE for equal-length aligned arrays. Invalid calls leave output arrays unchanged; percentile returns NaN. GIM-16.01–09/.11–12 numerical foundations, GIM-16.10 preserves existing RasterImage.pixelAt. Regional/channel extraction and raster integration remain pending. No new dependencies. Group analysis-numeric: 30 checks, not yet executed.

## Raster regions

RasterImage.analysisSamples(x,y,width,height,channel,controlled,float[] output) extracts row-major regional samples (0–255); channel 0–3 RGBA, 4 Rec.709 weighted encoded RGB luma (not linear-light luminance). controlled=0 raw buffer, 1 existing export controls with byte rounding. No alpha weighting or implicit exclusion of transparent pixels. Output must contain exactly width*height values, maximum 4,194,304. Invalid requests preserve output and image. Use MediaAnalysis.summary/percentile/countRange/histogram/compare for statistics; proportion is count divided by region sample count. GIM-16 regional/channel analysis, mean sampling and aligned image comparison foundations; arbitrary selection masks and perceptual comparison remain outside this adapter.
