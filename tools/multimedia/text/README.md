# TextIO (experimental)

Procedural Unicode text, with no markup or CSS. TextStyle owns font family, absolute pixel size (1–512), bold/italic/underline flags (0/1), packed RGB (0–0xffffff). Defaults Sans 16px, black, regular. Property setters return accepted value or -1 (empty string for invalid font); invalid input preserves state. inherit(style) copies properties. TextDocument owns ordered paragraphs with style snapshots; addParagraph(text,style), paragraphCount(), paragraphText(index), setParagraphText(index,text), setParagraphStyle(index,style), removeParagraph(index), clear(). UTF-8 validated, 64 KiB per paragraph, 1 MiB total, 4096 paragraphs. Empty paragraphs allowed. Invalid index text query returns empty string. measureParagraph(index,width,int[] dimensions) uses Pango/Cairo plain-text layout, word/character wrapping, width 1–4096 pixels, exact two-element output [logical width,height] in pixels; invalid input preserves output. Font fallback and measurements depend on installed fonts. Style changes affect stored paragraphs only via setParagraphStyle. No new package dependencies: pangocairo and GLib already used. This first stage does not render/export documents or implement mixed inline styles, tables or real-time processing. Native validation pending.

## Advanced typography

TextStyle adds weight (100–1000, default 400; bold getter is true at >=700, bold setter selects 400 or 700), strikethrough (0/1), backgroundColor (-1 disabled or packed RGB), letterSpacing (-32..128 pixels), baselineShift (-512..512 pixels, positive upwards), script (0 normal, 1 superscript, 2 subscript), opacity (0..1). Script scales glyphs to 70% and adds a baseline shift of +0.35 or -0.2 times original font size; explicit baselineShift is additive. These are procedural Pango attributes, no markup parsing. Invalid integer setters return -1 except backgroundColor (-2); invalid float setters return NaN; state remains unchanged. Inheritance and paragraph snapshots include all attributes. Colors, background, opacity and decorations are prepared in the layout for later rendering; this release exposes measurements, not visible output. Measurements depend on installed fonts. Native validation pending.

## Inline runs

TextRun owns UTF-8 text and a style snapshot. set(text,style), setText(text), setStyle(style), text(). TextDocument.appendRun(paragraph,run) appends a nonempty run after the original base text; runCount, runText, setRun, setRunStyle, removeRun address appended runs only (zero-based). paragraphText returns the concatenated base and run texts. setParagraphText replaces the complete content and discards runs; setParagraphStyle changes only the base style. Run snapshots are independent of later object edits. Maximum 1024 appended runs per paragraph and 16384 per document, existing byte limits still apply. Pango receives byte-range attributes for each UTF-8 segment; no markup. KeyframeCurve values can be assigned to TextStyle and applied using setRunStyle. Rendering pending; native smoke validation pending.

## Paragraph layout

TextParagraphStyle separates block layout from glyph style. alignment: 0 left, 1 center, 2 right, 3 justify (last line not justified; automatic RTL can mirror left/right). wrapMode: 0 word with character fallback, 1 character, 2 word only. direction: 0 automatic, 1 LTR, 2 RTL. lineSpacing is extra pixels between lines (0..512), indent first-line offset (-1024..1024; negative hanging indent), marginLeft/Right/Top/Bottom (0..2048 px). Defaults zero. Invalid int setters return -1; invalid float setters return NaN; unchanged state. inherit copies properties. setParagraphLayout(index,style) stores a snapshot, getParagraphLayout(index,style) copies it out. Content and inline styles remain independent. measureParagraph includes margins; measureDocument(width,int[2]) returns max paragraph logical width and sum of heights (no collapsing margins, no pagination). Width 1..4096, positive inner width and absolute indent smaller than inner width required. Word-only wrapping may overflow horizontally. Measurements are logical, not ink bounds; rendering pending. Both measurement APIs share makeLayout for future rendering. Keyframes can control all numeric properties. Native validation pending.

## Raster rendering

TextDocument.exportPixels(width,height,backgroundRGB,int[] pixels) renders the document to straight RGBA8, row-major, exact width*height*4 elements. savePNG(path,width,height,backgroundRGB) saves a new lowercase .png file (never overwrites). Background -1 is transparent, otherwise packed RGB opaque. Dimensions 1..4096, at most 4194304 pixels. Shared Pango layout includes mixed runs and paragraph properties. Paragraphs stack vertically with measured rounded heights; horizontal content is clipped to margins and canvas, vertical overflow clipped to canvas; no pagination or scrolling yet. All layouts validated even if offscreen. Empty documents render background only. Invalid requests leave arrays unchanged and do not create output files. Compatible with RasterImage.importPixels and, with opaque background, VideoWriter.appendFrame. Glyph appearance depends on installed fonts. Rendering is synchronous/offline, not audio-thread safe. No new dependencies. Native validation pending.

## Paragraph containers

TextContainer is a reusable box configuration attached to one paragraph via setParagraphContainer(index,box); getParagraphContainer copies its snapshot out. paddingLeft/Right/Top/Bottom 0..512 px, borderWidth 0..128 px, borderColor packed RGB, backgroundColor -1 transparent or packed RGB, opacity 0..1 for the whole decorated paragraph. Defaults are zero padding/border, transparent background, opacity 1. inherit copies all properties. Invalid setters preserve state (NaN for floats, -1 for borderColor, -2 for backgroundColor). Margins remain external; padding and border reduce the available line width and increase logical measured dimensions. The painted box fills the available width between margins; measurements report logical content width plus padding/borders/margins rather than the painted width. Decorated content is clipped inside the box. Opacity composites the entire box as a group, including text. Zero opacity preserves layout. Existing default paragraph rendering is unchanged. Container snapshots survive text edits; no nested or multi-paragraph containers yet. KeyframeCurve can control numeric properties. Native validation pending.

## List items

TextList configures an individual paragraph list marker. mode 0 none (default), 1 bullet, 2 decimal number with period, 3 custom marker. number 1..999999 (default 1), level 0..16, levelIndent 0..128 px (default 20), markerWidth 1..512 px (default 32). marker accepts nonempty UTF-8 up to 64 bytes, no tabs or line breaks, default '*'. setParagraphList(index,list) copies a snapshot; getParagraphList copies it out; paragraphListLabel returns the computed marker separately from paragraphText. Numbers are explicit, allowing procedural numbering; no automatic renumbering or nested list tree yet. Marker uses base text style, a left-hand gutter of level*levelIndent+markerWidth, with wrapping confined to body; marker clipped to its gutter. Height includes both marker and body. Container opacity applies to both. Text and run editing preserve list metadata. Numeric properties can be driven by keyframes. Invalid setter preserves state, returns -1 for ints, NaN for floats, empty string for marker. Native validation pending.

## Tables

TextTable.create(rows,columns) resets a rectangular table, 1..256 rows, 1..32 columns, at most 1024 cells. rows(), columns(), setCell(row,column,text,TextStyle), cellText, setCellLayout(row,column,TextParagraphStyle), setCellContainer(row,column,TextContainer), columnWeight(column[,value]) (0.01..100, default 1). Cell indices zero-based. Cells default to 1 px black border, 4 px padding and transparent background. Each row takes the maximum measured cell height, cells fill that row, columns share available width by relative weight with rounded cumulative boundaries. Borders are independent, not collapsed. Text wraps within each cell. TextDocument.appendTable(table) takes a snapshot at the current paragraph insertion boundary, setTable(index,table) replaces it in place, tableCount(), removeTable(index). Tables and paragraphs render in insertion order; removing a paragraph adjusts table boundaries, clear removes all. paragraphCount and paragraphText exclude tables. Document table limits 256 tables, 4096 cells, 1 MiB cell text in addition to paragraph budget. No spanning, nested tables or mixed runs in cells yet. Document measurement includes full table width and row heights. Invalid layouts leave output arrays unchanged. Native validation pending.

## Editorial grids

TextGrid.create(rows,columns) creates a rectangular panel layout with transparent, borderless, unpadded panels by default. Limits and columnWeight semantics match TextTable. setPanel(row,column,text,TextStyle), panelText, setPanelLayout, setPanelContainer customize panels. columnGap and rowGap are integer pixels 0..512, default 0, invalid returns -1. Gaps are excluded before allocating relative column widths and included between measured row heights; no outer gap. Gaps reveal canvas background. Numeric controls accept keyframe values (integer conversion for gaps). TextDocument.appendGrid, gridCount, setGrid, removeGrid use independent zero-based grid indices, preserving interleaved paragraph/table/grid insertion order and snapshots. Table and grid blocks share the existing aggregate limits. No panel spans, multi-paragraph panels, nested panels or free positioning yet. Native validation pending.

## Pagination

TextPage is reusable page configuration: width/height 1..4096 px (default 640x480), marginLeft/Right/Top/Bottom 0..2048 integer pixels, backgroundColor packed RGB or -1 transparent (default white). Canvas limit 4194304 pixels and positive content area required. TextDocument.pageCount(page) returns number of pages (empty document one blank page), -1 on invalid layout. exportPage(page,index,int[] pixels) produces straight RGBA8, exact page.width()*page.height()*4 elements; savePagePNG(path,page,index) creates new lowercase PNG, never overwrites. Indices zero-based. Greedy pagination preserves paragraph/table/grid insertion order, moving whole blocks to the next page when necessary; any block taller than the available content height rejects the entire plan, rather than silently clipping. No paragraph or table row splitting, headers/footers or explicit breaks yet. Maximum 4096 pages. Each query recomputes the plan; numeric settings can be changed by keyframes. Rendering shares the existing document drawing engine, clips to the page content area, and leaves ordinary exportPixels/savePNG behavior unchanged. Native validation pending.
