# MediaGeometry

Import with `@import "MediaGeometry";`. Each object has independent guide and grid state. Axis 0 is X (vertical guide), axis 1 is Y (horizontal guide). Guide indices are zero-based, removal compacts indices. Relative positions are percentages 0–100, resolved against the supplied nonnegative extent. Absolute coordinates may be negative. Grid spacing must be positive; offsets are arbitrary finite coordinates. Snap uses nearest grid line, ties away from zero relative to origin. Invalid mutation returns 0 without changing state; successful mutation returns 1. Invalid numeric results return NaN; invalid guide axis returns -1. Align returns the origin that places the selected anchor (0=start, .5=center, 1=end) at target. Distribute interpolates between reference coordinates with fraction 0–1; callers can use i/(n-1) for uniform reference spacing. Equal gaps for unequal-sized objects and domain adapters remain separate work. No UI, external dependency, file metadata, or changes to existing geometry APIs.

Trace: GIM-36.01–08, GIM-36.09–10 (numeric alignment primitive; aliases GLX-24.03/.04 and SCR-13.02/14.02), GIM-36.11–12 (numeric reference distribution), GIM-36.13 (numeric references). Full family certification remains pending domain integration and Windows validation. Smoke group geometry-guides: 34 checks, not yet executed.

## MediaTransform2D

Independent row-major 3×3 homogeneous matrix, identity initially. Operations translate(x,y), scale(x,y) (negative factors reflect; zero factors allowed but singular), rotate(radians), shear(x,y) are applied in call order to column vectors. setMatrix accepts nine row-major coefficients; matrixAt uses index 0–8; mapX/mapY divide by homogeneous w. invert is transactional, returns 0 for singular/nonfinite inverse. Invalid numeric queries return NaN. No raster resampling or 3D projection implemented here; these require adapters and separate validation. Trace GIM-08.01–11/.15 numerical foundations, KDN-36.01, KDN-37.01–04, KDN-51.01/.02/.04 aliases. GIM-08.12–14 remain pending. New group geometry-transforms: 31 checks, not yet executed.

## MediaDeformation2D

Independent displacement grid (2–1024 points per axis), configured by width, height, origin and positive spacing. setPoint/pointX/pointY address zero-based control points; sampleX/sampleY bilinearly interpolate displacement in coordinate units, returning zero outside the grid and NaN for invalid/unconfigured queries. For inverse resampling, consumers can use source = destination + displacement; no raster application is implied. move adds local translation; radial adds signed radial expansion/contraction; twist adds signed local angular displacement; all use linear radial falloff. smooth blends with the original 3×3 neighborhood mean, erase blends toward zero; strength 0–1. Operations are additive field edits, not exact composition of successive spatial transforms. configure resets, clear zeros without changing geometry; invalid mutations return 0 and preserve state. Displacement maps can be read/written via point access; image import/export and domain adapters remain pending. Trace GIM-09.01–10 numerical field foundations only. Group geometry-deformation: 44 checks, not yet executed.

## RasterImage adapters

warpMatrix(width,height,inverseMatrix,filter,border) accepts a row-major 3×3 destination-to-source matrix, obtainable from MediaTransform2D.invert()/matrixAt. warpDisplacement(width,height,displacements,filter,border) accepts interleaved dx,dy for every destination pixel, e.g. sampled from MediaDeformation2D. Filter 0 nearest / 1 bilinear with premultiplied alpha; border 0 transparent / 1 clamp. Integer coordinates are pixel centers. Invalid dimensions, arrays, coefficients or modes fail without modifying the image; undefined projective points become transparent. Existing RasterImage controls are retained. Trace GIM-08.01–11/.13–15 and GIM-09.01–10 raster adapters, with GIM-08.12 3D projection, vector/video adapters, image-map I/O, path operations GIM-07 and equal-gap distribution still residual. ## Equal gaps and 3D projection

MediaGeometry.equalGapPosition(first,last,totalSize,prefixSize,count,index) returns the start of an ordered item with equal nonnegative gaps between items of potentially unequal size. first/last are outer edges; totalSize is the sum of all sizes and prefixSize the sum of sizes before index. Caller supplies consistent sizes and order. At least two items required. Invalid input or insufficient space returns NaN. MediaGeometry.projectPoint(matrix,x,y,z,result) maps a 3D point through a row-major 4×4 homogeneous matrix and divides by w; writes exactly three result values only on success. This is a numeric projection primitive, not camera clipping, mesh rendering or raster 3D transformation. Trace GIM-36.11–12 and GIM-08.12 partial foundations. Group geometry-projection: 20 checks, not executed.

## Editable vector paths

VectorImage.addPath(commands,rgb,alpha), getPath(index), setPath(index,commands) use the existing editable shape model and transactional replacement. Explicit uppercase absolute M/L/Q/C/Z commands, whitespace-separated finite coordinates, maximum 4096 commands, no implicit repeats or relative syntax. Q and C carry quadratic and cubic Bézier control points. Multiple subpaths may be supplied; Z closes the current drawn subpath. Existing SVG H/V path import remains compatible. Styles, shape transforms, duplication/removal and SVG save/load reuse existing APIs. GIM-07 partial foundations; path reversal, joining semantics, selection conversion and raster fill/stroke adapters remain pending. Group geometry-vector-paths: 26 checks, not executed.

## Path operations

VectorImage.reversePath(index) reverses each canonical M/L/Q/C/Z subpath, preserving quadratic controls and swapping cubic controls. Closed paths remain closed, with start moved to the previous final explicit endpoint. Subpath order stays unchanged. VectorImage.joinPaths(first,second) combines two paths as compound subpaths, keeping the first shape's attributes and removing the second; requires identical serialized non-d attributes (conservative restriction, including transform and style). This is not geometric boolean union. Invalid mutations preserve state. Legacy H/V syntax is not accepted by these operations. Trace GIM-07.04/.09 and associated GLX aliases, partial; boolean operations and selection/raster conversion remain separate. Group geometry-path-operations: 30 checks, not executed.

## Raster selection conversion

VectorImage.importSelection(width,height,mask,threshold,rgb,alpha) replaces the editable canvas with a compound M/L/Z path consisting of horizontal selected runs (threshold inclusive, 8-bit input, max 819 runs and 4,194,304 pixels). Empty selection creates an empty canvas. This is an exact native-resolution binary representation, not smooth contour tracing or preservation of soft alpha. Use existing exportAlpha for path-to-mask, exportPixels and RasterImage.importPixels for filled/stroked raster output, and existing shape style setters for fill/stroke. Internal run edges can appear if stroked; this is not a contour stroke algorithm. GIM-07.11–14 partial conversion and rendering evidence; contour simplification, soft masks and compositing adapters remain pending. Group geometry-selection-paths: 49 checks, not executed.
