# MediaGeometry

Import with `@import "MediaGeometry";`. Each object has independent guide and grid state. Axis 0 is X (vertical guide), axis 1 is Y (horizontal guide). Guide indices are zero-based, removal compacts indices. Relative positions are percentages 0–100, resolved against the supplied nonnegative extent. Absolute coordinates may be negative. Grid spacing must be positive; offsets are arbitrary finite coordinates. Snap uses nearest grid line, ties away from zero relative to origin. Invalid mutation returns 0 without changing state; successful mutation returns 1. Invalid numeric results return NaN; invalid guide axis returns -1. Align returns the origin that places the selected anchor (0=start, .5=center, 1=end) at target. Distribute interpolates between reference coordinates with fraction 0–1; callers can use i/(n-1) for uniform reference spacing. Equal gaps for unequal-sized objects and domain adapters remain separate work. No UI, external dependency, file metadata, or changes to existing geometry APIs.
